# Chapter IV — Exercise 00: Personal Portfolio

An authentic, responsive personal portfolio website built from scratch using pure Vanilla technologies without any frameworks, templates, or UI libraries.

## Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Flexbox, CSS Grid, Custom Properties, Media Queries)
- **JavaScript ES6+** (DOM manipulation, Theme Switcher logic, and `localStorage` persistence)
- **Git** (Version control)

## Features
- **Responsive Layout:** Automatically adapts to all screen sizes using CSS Grid (`auto-fit`) and Flexbox without breaking.
- **Dynamic Theme Switcher:** Interactive button to toggle seamlessly between Dark and Light modes with persistent state preservation using `localStorage`.
- **Semantic Structure:** Clear separation of required sections including About Me, Skills, Projects Showcase (00-03), Hobbies, and a functional Contact Form.
